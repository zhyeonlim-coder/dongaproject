중앙 서버 E2E 검사

Vercel Postgres 에 실제로 쓰고, 실제로 다시 읽고, 저장이 실패할 때 되돌아가는지 확인합니다. 다른 검사들은 모두 가짜 저장소 위에서 돌지만 이 검사만 진짜 DB 를 건드립니다.

이 검사는 로그인한 상태에서만 의미가 있습니다. 먼저 로그인 화면에서 서버 접속 비밀값을 넣어 서버에 연결한 뒤 이 페이지를 여세요. 연결되어 있지 않으면 1번 그룹만 보고 멈춥니다.

쓰기는 모두 batch:__E2E__ 라는 어느 화면에도 없는 범위에 하고, 끝나면 지웁니다. 실제 배치에는 ws_E2E검사@v 라는 추가 열 하나만 적었다가 되돌립니다 — 원본 Excel 항목은 읽기만 합니다. 씨앗 심기와 전체 비우기는 돌리지 않습니다.
